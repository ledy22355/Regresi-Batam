Intercept/Penjelasan Hasil

Variabel yang digunakan: Biaya Pendidikan (X1) dan Biaya Kesehatan (X2) sebagai variabel independen, serta Kemiskinan (Y) sebagai variabel dependen.

1.Intercept (8,40): Titik awal tingkat kemiskinan Kota Batam jika biaya pendidikan dan kesehatan bernilai nol. Nilainya tidak signifikan (p = 0,062), jadi hanya berfungsi sebagai titik awal garis regresi.

2.Biaya Pendidikan (0,0062): Arahnya positif, tetapi tidak berpengaruh signifikan terhadap kemiskinan (p = 0,586 > 0,05).

3.Biaya Kesehatan (0,0138): Arahnya positif, tetapi juga tidak berpengaruh signifikan (p = 0,388 > 0,05).

4.Uji F (p = 0,583): Secara bersama-sama, kedua variabel tidak berpengaruh signifikan terhadap kemiskinan.

5.R² (0,126): Kedua variabel hanya menjelaskan sekitar 12,6% perubahan kemiskinan. Sisanya (87,4%) dipengaruhi faktor lain di luar model.

6.Grafik 3D: Titik merah (data aktual) menyebar jauh dari bidang regresi, dan bidangnya tampak hampir datar. Ini sesuai dengan hasil di atas: model lemah, dan kedua variabel tidak punya hubungan yang kuat dengan kemiskinan.

Kesimpulan: Biaya pendidikan dan biaya kesehatan tidak berpengaruh signifikan terhadap kemiskinan di Kota Batam (2014-2024), baik sendiri-sendiri maupun bersama-sama.
